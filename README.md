# 🚀 Как использовать (Пошаговое руководство)

## Шаг 1: Форк репозитория

1. Войдите в GitHub и сделайте **Fork** этого репозитория.
2. Или, если вы создали репозиторий сами, используйте его напрямую.

## Шаг 2: Запуск в Codespaces

1. Нажмите на кнопку **Code**.
2. Перейдите на вкладку **Codespaces**.
3. Нажмите **Create codespace on main**.
4. Подождите, пока контейнер будет создан (около 2-3 минут).

## Шаг 3: Получение ссылки на прокси

После завершения сборки в терминале отобразится ссылка VLESS. Скопируйте её.

## Шаг 4: Настройка порта (Очень важно)

- В среде Codespace откройте вкладку **PORTS** (Порты).
- Найдите порт **443**.
- Щелкните по нему правой кнопкой мыши и выберите **Visibility** > **Public**.

## Шаг 5: Подключение

Вставьте скопированную ссылку в ваше прокси-приложение.

# 📖 Руководство по использованию (Usage)

## 🔗 Получение и использование ссылки

После запуска Codespace ссылка VLESS автоматически появится в терминале. Достаточно:

1. Скопировать ссылку целиком (от `vless://` до самого конца).
2. Вставить её в ваше клиентское приложение (большинство приложений распознают ссылку при нажатии кнопки `+` или `Import from clipboard`).
